## 二、五句必须说准的话

1. **本地优先** = 数据在本地 SQLite + 排期计算不依赖模型 + 模型层可整体换成本地 Ollama / vLLM。默认用云模型是部署选择，不是架构妥协。
2. **ReAct** = 按"推理—行动—观察"组织闭环，动作由原生 Function Calling 表达，**不在文本里解析 `Thought/Action`**。
3. **补偿事务** = `restore()` 先删六张表全部行、再按依赖顺序重灌快照。**是整表覆盖，不是事务**：无隔离、无崩溃原子性。
4. **24 次** = 轮末检查的预算保护，**不是逐次硬上限**；参数去重只防同一 run 内的重复。
5. **评测** = Mock 场景证明"系统链路通"，**不证明**真实模型的理解准确率。

## 三、七条"不等于"（最重要的一屏）

```
schema 白名单      ≠  执行权限（dispatch 未复核）
调用去重          ≠  业务幂等（跨请求仍会重复写）
读窗口无状态       ≠  会话串行（同 session 并发写仍会交错）
pending 落库      ≠  并发只执行一次（无原子领取）
补偿恢复          ≠  原生事务（无隔离、无崩溃原子性）
执行后审计        ≠  自动回滚（当前只追加 warning）
FEASIBLE          ≠  已证明最优（不等于 OPTIMAL）
```

## 六、五条追问链（练到能一口气答完）

**A 工具安全**
为什么要白名单 → 在哪过滤 → 模型伪造被隐藏的工具怎么办 → 确认阶段还校验吗 → 提示注入怎么绕过模型侧约束 → 怎么测服务器真的没执行

**B 事务**
为什么用补偿 → commit 过还能撤吗 → 其他请求写入会被覆盖吗 → 进程崩溃怎么办 → 外部日历写入怎么撤 → 怎么设计 UoW 和幂等

**C 记忆**
模型看哪些上下文 → 为什么是 10 条 → 截断丢了约束怎么办 → 工具历史持久化吗 → 多 worker 一致吗 → 什么时候才需要语义记忆

**D 评测**
283 个测试测了什么 → Mock 能证明模型效果吗 → 真实评测怎么设计 → 路径不同算错吗 → 怎么测确认安全 → 怎么避免调 prompt 过拟合

**E 规划**
为什么用求解器 → 变量和目标是什么 → FEASIBLE 和 OPTIMAL 差在哪 → 地图约束怎么接进去 → 13 轮后还不合法怎么办 → 总时间预算怎么设

## 七、已核实的原稿错误（✅ 可以放心引用，带出处）

> 这些是 `interview-prep.md` 里真实存在、且经代码验证为**错**的说法。讲出来是加分项——"我知道我上一版笔记哪里写错了"。

| # | 原稿说法（出处） | 事实 |
|---|---|---|
| 1 | "模型侧还是单轮 function-calling"（L52） | 是多轮工具循环，同一请求反复调模型 |
| 2 | "排序键是全序，不会有并列项"（L139） | 无最终 ID tie-breaker，同键时靠 Python 稳定排序 |
| 3 | "SQLite 默认不开 SAVEPOINT，所以不能用"（L290） | 归因错误；问题是 commit 边界与驱动事务模式 |
| 4 | "路线缓存 TTL 24 小时"（L418） | 路线 **5 分钟**；24 小时是地点搜索；地理编码 30 天 |
| 5 | "用 MockProvider + 自建 SSE 绕开流式需求"（L451） | **代码里没有任何 SSE**，接口一次返回完整 JSON |
| 6 | "9 张表"（L460、L495） | 14 张表；常用地点表叫 `saved_locations` |
| 7 | "改时区偏好后显示层统一转换"（L479-489） | 主日历按**浏览器时区**渲染，未统一按 `preferences.timezone` |
| 8 | "五个指标"（L532） | metrics 七项：四项质量率 + 耗时 / token / 费用 |
| 9 | "只依赖 6 个库"（L65、L232、L442） | 直接运行依赖 6 项；测试还需额外包，不能称"零其他依赖" |
| 10 | "黄金用例做基线回归"（L778） | 原稿是**下一步建议**，当前未实现人工黄金库 |
| 11 | `transaction.py` 注释：工具提前 commit 后"重建也救不回来" | **错。** restore 删全表重灌，commit 过也能恢复；`test_restore_rolls_back_partial_insert` 已证 |

**其中第 5 条最危险**——"自建 SSE"如果被追问"你的流式怎么做的"，会当场穿帮。第 11 条最适合主动讲：**注释写错了、测试才是真相**。
