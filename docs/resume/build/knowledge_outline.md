# 使用说明

这不是一份书单，是一份**能力目录**。每一项都给出三样东西：要学什么、学到什么程度算会、和你的项目怎么接上。

**优先级定义。**

| 级别 | 含义 | 投入建议 |
| --- | --- | --- |
| P0 | 面试必问，或简历上写了就必须能答 | 先学，学到能讲 3 分钟并接住两层追问 |
| P1 | 岗位 JD 高频出现，决定竞争力 | 学到能讲清取舍，不要求手写实现 |
| P2 | 加分项，特定团队才会深挖 | 知道边界和术语，被问到不慌 |

**什么叫“掌握”。** 不是看过文章，而是满足三条：能用一句话说清它解决什么问题；能说出至少一个取舍或失败模式；能在自己的项目里指出对应的代码位置或改造点。

**学习闭环。** 每个模块按“读一遍 → 写一个最小实现 → 接进 PlanPilot → 准备一段 60 秒表述”走完，才算完成。只看不写，面试时一定露。

## 0.2 四周与八周两条路径

# 第 1 章 LLM 基础与推理

## 1.1 Transformer 与注意力机制（P1）

- 必学：自注意力的 QKV 计算；多头注意力的作用；位置编码；残差与归一化；Encoder-only、Decoder-only、Encoder-Decoder 的差别。
- 掌握标准：能解释为什么 Decoder-only 适合生成式 Agent，以及注意力复杂度为什么随上下文长度平方增长。
- 关联：理解上下文窗口的成本来源，才能解释为什么要裁剪。

## 1.2 Token 与上下文窗口（P0）

- 必学：BPE 分词；中英文 token 比例差异；上下文窗口与最大输出；截断与滑窗；长上下文的注意力成本。
- 掌握标准：能估算一段中文 prompt 的 token 量，并解释为什么字符裁剪只是近似。
- 关联：PlanPilot 的 `estimate_tokens`（中文 1 字 1 token、其余 3.5 字符 1 token，再乘 1.1 安全系数）就是这一层的工程取舍。

## 1.3 采样参数（P1）

- 必学：temperature、top_p、top_k、max_tokens、stop、seed 的作用；什么场景要确定性；结构化输出为什么要低温度。
- 掌握标准：能解释“低温度不等于结果可复现”，以及为什么 Agent 的可靠性不能只靠 seed。
- 关联：工具参数生成需要稳定，但真正的保证是 schema 校验和业务校验。

## 1.4 KV Cache 与 PagedAttention（P1）

- 必学：KV Cache 复用的原理；prefill 与 decode 两阶段；PagedAttention 的分页管理；prefix caching 与 prompt caching 的计费差异。
- 掌握标准：能解释为什么固定 system prompt 适合做前缀缓存，以及它省的是哪一部分钱。
- 关联：PlanPilot 的 system prompt 较长且稳定，是天然的缓存前缀。

## 1.5 Continuous Batching（P2）

- 必学：静态 batch 与连续批处理的区别；请求如何在 token 级插队；吞吐与延迟的权衡。
- 掌握标准：能解释 vLLM 相对裸 transformers 快在哪里。
- 关联：自建推理服务时才需要，当前用云 API 不涉及。

## 1.6 量化（P2）

- 必学：INT8、FP8、AWQ、GPTQ 的基本原理；精度损失；显存换算。
- 掌握标准：能估算 7B 模型在 FP16 与 INT4 下的大致显存占用。
- 关联：决定能不能把模型放到本地，是“本地优先”能否彻底成立的前提。

## 1.7 推理服务与部署（P1）

- 必学：vLLM、SGLang、Ollama 的定位；OpenAI 兼容端点；自建与云 API 的成本对比；并发与限流。
- 掌握标准：能说清什么规模自建划算，什么情况直接用云。
- 关联：PlanPilot 的 LLM 抽象层可以在这些实现之间切换。

## 1.8 成本模型与缓存计费（P0）

- 必学：输入输出分别计价；缓存命中折扣；失败请求是否计费；token 预算与请求 deadline；模型路由。
- 掌握标准：能给自己项目算一笔账：一次对话多少 token、多少钱、缓存能省多少。
- 关联：AgentRun 里已有 token 与估算费用字段，但还没有硬限额。

# 第 2 章 Prompt 与结构化输出

## 2.1 Prompt 结构（P0）

- 必学：角色、任务、约束、示例、输出格式的分层；system 与 user 的职责边界；少样本示例的副作用。
- 掌握标准：能说清哪些内容该进 system，哪些该进 user，哪些根本不该进 prompt。
- 关联：PlanPilot 的 system 里放通用规则、时区、Skill 提示，业务状态单独做摘要。

## 2.2 Function Calling 协议（P0）

- 必学：工具 schema 的结构；tool_calls 与 tool 消息的配对；并行调用；参数是 JSON 字符串；模型可能编造工具名。
- 掌握标准：能画出一次完整的多轮消息序列，并指出每一轮可能的失败点。
- 关联：这是 Agent Loop 的底座，必须能脱稿讲。

## 2.3 JSON Schema 与结构化输出（P1）

- 必学：JSON mode 与严格 schema 的区别；必填与可选；枚举与范围；额外字段；解析失败的处理。
- 掌握标准：能解释“模型输出合法 JSON”和“参数语义正确”是两件事。
- 关联：当前 Registry 没有统一执行 schema 校验，这是明确缺口。

## 2.4 上下文工程（P0）

- 必学：上下文的分区与预算；历史压缩；工具结果裁剪；状态摘要；什么时候该重新查询而不是塞更多历史。
- 掌握标准：能给出一个可执行的预算分配方案，而不是“尽量短”。
- 关联：PlanPilot 分三档预算（单条 1200 / 历史 3600 / 整包 18000 token），仍属规则驱动，没有摘要层。

## 2.5 提示注入与防御（P0）

- 必学：直接注入与间接注入；外部内容为什么不能当指令；权限与提示词的分工；工具白名单的作用边界。
- 掌握标准：能设计一个“恶意工具返回”测试，验证服务器确实没执行越权动作。
- 关联：PlanPilot 有确认和业务校验，但没有完整的注入防御体系。

# 第 3 章 Agent 架构

## 3.1 ReAct 与工具循环（P0）

- 必学：Reasoning 与 Acting 的交替；文本 ReAct 与 Function Calling 实现的区别；终止条件；观察回传。
- 掌握标准：能说清“为什么 Function Calling 不需要写解析器”，以及它的代价。
- 关联：PlanPilot 的 Agent 层就是这一套。

## 3.2 Plan-and-Execute（P1）

- 必学：先规划后执行的结构；计划校验；失败后的重规划；与 ReAct 的适用边界。
- 掌握标准：能说清什么时候该先出计划，什么时候边做边看更合适。
- 关联：项目里的“规划”是业务排期，不是 Agent 执行计划，别混。

## 3.3 Reflection 与自我修正（P2）

- 必学：反思循环；批评与重写；成本代价；何时停止。
- 掌握标准：能解释反思为什么容易变成“反复改但不变好”。
- 关联：可作为写操作前的自检机制，但当前没做。

## 3.4 工具设计原则（P0）

- 必学：粒度；命名与描述；参数设计；幂等性；错误语义；读写分离；确认等级。
- 掌握标准：能判断一个操作该做成一个工具还是多个工具。
- 关联：PlanPilot 的 37 个工具就是这套原则的实践。

## 3.5 记忆分层（P0）

- 必学：会话记忆、长期偏好、语义记忆、执行状态；各自的存储与生命周期；遗忘与冲突。
- 掌握标准：能说清“什么该记、记在哪、什么时候删”。
- 关联：当前只有会话文本和结构化偏好，没有语义记忆。

## 3.6 循环控制与预算（P0）

- 必学：迭代上限；总调用预算；单工具额度；参数级去重；无工具收尾；预算应该在哪一层检查。
- 掌握标准：能指出“轮末检查”和“调用前预占”的差别。
- 关联：PlanPilot 的 12 轮、24 次、逐工具额度。

## 3.7 人机确认（P0）

- 必学：确认等级；批量确认；预览与执行分离；确认过期；确认幂等；危险操作的最小授权。
- 掌握标准：能设计 pending → executing → succeeded 状态机。
- 关联：pending_actions 表与确认分支。

## 3.8 持久执行与恢复（P1）

- 必学：执行游标；步骤状态；幂等键；崩溃恢复；外部副作用补偿；durable execution 框架。
- 掌握标准：能说清“重启后恢复到哪一步、怎么避免重复写”。
- 关联：当前只能恢复会话文本，不能恢复执行。

## 3.9 多 Agent（P1）

- 必学：角色划分；通信成本；共享状态；冲突解决； supervisor 与 swarm 模式。
- 掌握标准：能给出“什么条件下才值得拆”的判断依据。
- 关联：PlanPilot 是单 Agent 多 Skill，不是多 Agent。

## 3.10 可观测性（P1）

- 必学：trace、span、run_id；模型调用与工具调用的关联；错误分类；脱敏；成本归集。
- 掌握标准：能设计一张能回答“这次为什么失败”的轨迹表。
- 关联：AgentRun 已有基础字段，但还不是完整 tracing。

# 第 4 章 RAG（检索增强生成）

## 4.1 文档解析（P1）

- 必学：PDF、Word、HTML、扫描件的解析差异；表格与版式；OCR；清洗与去噪。
- 掌握标准：能说清“解析质量决定 RAG 上限”。
- 关联：若给 PlanPilot 加会议纪要导入，这是第一步。

## 4.2 Chunking（P0）

- 必学：固定窗口、重叠窗口、按结构切；重叠率；父子分块；元数据保留。
- 掌握标准：能给出一个具体切分方案，并解释为什么这样切。
- 关联：切不好，后面检索和重排都救不回来。

## 4.3 Embedding（P0）

- 必学：向量维度；训练目标；归一化；相似度度量；中文模型选型；dense 与 sparse。
- 掌握标准：能说清选型依据，而不是“大家都用这个”。
- 关联：你的科研做过对比学习，这里可以直接迁移理解。

## 4.4 向量索引（P1）

- 必学：暴力检索；HNSW；IVF；PQ；召回率与延迟的权衡；参数影响。
- 掌握标准：能解释近似检索牺牲了什么、换来了什么。
- 关联：小数据量用暴力检索就够，不要过度设计。

## 4.5 混合检索与 RRF（P0）

- 必学：BM25 与稠密向量各自擅长什么；倒数排名融合；为什么不能直接加权相加。
- 掌握标准：能说清 RRF 不需要分数归一化的原因。
- 关联：中文专有名词多的场景，混合检索收益明显。

## 4.6 Rerank（P0）

- 必学：粗排与精排；bi-encoder 与 cross-encoder；重排候选数；延迟代价。
- 掌握标准：能解释“为什么只对 top-50 重排”。
- 关联：这是区分“懂 RAG”和“调过 API”的关键点。

## 4.7 Query 改写（P1）

- 必学：HyDE；多查询扩展；查询分解；意图路由。
- 掌握标准：能说清每种改写适用什么问法。
- 关联：多跳问题必须分解，否则一次检索拿不全。

## 4.8 上下文组装与引用（P1）

- 必学：引用溯源；上下文压缩；去重；冲突证据；防注入标记。
- 掌握标准：能设计一个“答案必须带出处”的组装模板。
- 关联：和 Agent 的工具结果处理是同一类问题。

## 4.9 RAG 评估（P0）

- 必学：召回侧 hit rate、recall@k、MRR、NDCG；生成侧 faithfulness、answer relevancy、context precision。
- 掌握标准：能写一个评估脚本，输出 recall@5 和 faithfulness，而不是“效果不错”。
- 关联：和你已有的评测思路完全一致，可以直接复用。

## 4.10 Agentic RAG 与 GraphRAG（P2）

- 必学：检索作为工具；多轮检索；图结构索引；社区摘要。
- 掌握标准：能说清它们各自解决什么长尾问题。
- 关联：PlanPilot 的结构化查询已经接近“工具化检索”。

# 第 5 章 框架与协议

## 5.1 LangChain 与 LCEL（P1）

- 必学：Chain 与 Runnable；表达式语言；工具封装；记忆组件；生态与依赖体积。
- 掌握标准：能说清“链式组合”和“Agent 循环”的抽象差异。
- 关联：用来对比自研 Loop 的取舍。

## 5.2 LangGraph（P0）

- 必学：StateGraph；节点与边；条件分支；checkpointer 持久化；human-in-the-loop 中断与恢复。
- 掌握标准：能画出一个带分支、循环和人工中断的图，并说清状态怎么存。
- 关联：它的持久化和中断管理正是 PlanPilot 缺的部分。

## 5.3 LlamaIndex（P1）

- 必学：文档加载；索引类型；检索器与查询引擎；评估模块。
- 掌握标准：能跑通一个最小 RAG pipeline 并解释每层作用。
- 关联：如果重做 RAG，这是更合适的选择。

## 5.4 MCP（P0）

- 必学：Host、Client、Server 三角色；tools、resources、prompts；传输方式；权限边界。
- 掌握标准：能说清 MCP 解决的是“接入标准化”，不解决推理、授权和幂等。
- 关联：可以把 PlanPilot 的工具暴露给其他客户端。

## 5.5 A2A 与互操作（P2）

- 必学：Agent 间通信；能力发现；任务委派；与 MCP 的分工。
- 掌握标准：能说清“工具协议”和“Agent 协议”不是一回事。
- 关联：多 Agent 场景才需要。

# 第 6 章 后端与数据

## 6.1 FastAPI 与 Pydantic（P1）

- 必学：路由与依赖注入；请求响应模型；校验与错误处理；异步与同步的边界；OpenAPI。
- 掌握标准：能解释为什么“接口能跑”不等于“输入可信”。
- 关联：AgentChatRequest 的校验就是这一层。

## 6.2 SQLAlchemy Session（P0）

- 必学：Session 生命周期；identity map；flush 与 commit；expire 与 expunge；DetachedInstanceError；事务嵌套。
- 掌握标准：能解释“对象过期”和“对象分离”的区别，以及为什么回滚后旧对象不能直接用。
- 关联：六表快照恢复时要清理身份映射，正是这一层。

## 6.3 事务、隔离级别与锁（P0）

- 必学：ACID；四种隔离级别；脏读、不可重复读、幻读；行锁与表锁；乐观并发与版本号；SAVEPOINT。
- 掌握标准：能解释为什么“补偿”不等于“事务”，以及隔离性到底保证了什么。
- 关联：PlanPilot 的补偿方案最大的短板就是没有隔离性。

## 6.4 幂等设计（P0）

- 必学：幂等键；唯一约束；状态机；原子领取；重试与超时；外部副作用。
- 掌握标准：能设计一个“重复请求只产生一次业务效果”的接口，并说清崩溃窗口。
- 关联：确认请求重复提交是真实风险。

## 6.5 缓存（P1）

- 必学：TTL；LRU；缓存击穿、穿透、雪崩；一致性；单调时钟。
- 掌握标准：能解释为什么不同数据要设不同 TTL。
- 关联：路线 5 分钟、地点 24 小时、地理编码 30 天。

## 6.6 队列与异步任务（P1）

- 必学：生产者消费者；重试与死信；任务状态；幂等消费；长任务拆分。
- 掌握标准：能说清“请求内同步做完”和“丢到后台”的取舍。
- 关联：长排期和流式进度都需要这一层。

## 6.7 SSE 与 WebSocket（P1）

- 必学：SSE 协议；事件序号；断线重连；WebSocket 双向通信；背压。
- 掌握标准：能设计一个可续传的进度流，并说明为什么不能重放写操作。
- 关联：PlanPilot 当前完全没有流式。

## 6.8 可观测性（P1）

- 必学：结构化日志；指标；分布式追踪；错误分类；脱敏；采样。
- 掌握标准：能说清“可观测”和“可恢复”的区别。
- 关联：AgentRun 是起点，不是终点。

## 6.9 部署与多进程（P2）

- 必学：进程与线程；Gunicorn 与 Uvicorn；多 worker 的共享状态；SQLite 的并发限制；容器化。
- 掌握标准：能说清加 worker 之后哪些东西会失效。
- 关联：会话历史与模型故障状态都不在进程里，前者读表、后者是进程内状态机。

# 第 7 章 算法与优化

## 7.1 约束建模与 CP-SAT（P1）

- 必学：布尔变量与区间变量；NoOverlap；可选区间；线性约束；目标函数；FEASIBLE 与 OPTIMAL；求解预算。
- 掌握标准：能把一个排期问题写成变量、约束、目标三部分。
- 关联：PlanPilot 的优化模式就是这个模型。

## 7.2 贪心与启发式（P1）

- 必学：排序键；局部最优；什么时候贪心会坏；启发式修复。
- 掌握标准：能举一个“贪心排坏、全局优化排好”的具体例子。
- 关联：快速模式与优化模式的差别。

## 7.3 区间调度（P1）

- 必学：区间重叠判断；合并区间；带权区间调度；拆分任务。
- 掌握标准：能手写合并重叠区间，并说清时间复杂度。
- 关联：日程冲突检测的基础。

## 7.4 图算法（P1）

- 必学：拓扑排序；环检测；DFS 三色标记；Kahn 算法。
- 掌握标准：能手写依赖环检测，并区分“在栈上”和“已完成”。
- 关联：任务依赖的写入校验。

# 第 8 章 测试与评测

## 8.1 测试分层（P0）

- 必学：单元、集成、端到端；测试金字塔；测试替身；隔离数据库。
- 掌握标准：能说清每一层该测什么、不该测什么。
- 关联：PlanPilot 的 283 个测试分布在这几层。

## 8.2 Mock 与依赖注入（P0）

- 必学：脚本化模型输出；依赖注入；确定性；断言业务状态而不是调用顺序。
- 掌握标准：能设计一个“模型连续两次返回同一调用”的用例。
- 关联：MockProvider 的核心用法。

## 8.3 故障注入（P0）

- 必学：超时、限流、鉴权失败、工具异常、数据库失败、进程崩溃；故障点选择。
- 掌握标准：能列出一次写操作链路上所有可能失败的节点。
- 关联：确认批次失败恢复必须靠故障注入验证。

## 8.4 属性测试（P2）

- 必学：不变量；随机生成；失败样例缩减；与样例测试的区别。
- 掌握标准：能写出三条排期不变量，比如区间不重叠、不晚于截止。
- 关联：比单点断言更能发现边界问题。

## 8.5 LLM 评测集设计（P0）

- 必学：开发集与保留集；目标状态断言；允许路径；重复运行；失败分类；成本与延迟。
- 掌握标准：能设计一个不依赖固定工具顺序的评测方案。
- 关联：5 个 Mock 场景只是机制回归，不是效果评测。

## 8.6 LLM-as-judge（P1）

- 必学：评分 prompt；偏差；一致性；人工抽检；与规则指标的结合。
- 掌握标准：能说清“模型评分”什么时候可信、什么时候不能用于判定事实。
- 关联：解释质量可以用，数据是否正确不能只靠它。

## 12.2 怎么用这份清单

先闭卷答，录下来。答不上来的题，回到对应章节补，不要直接看答案。第二轮只答第一轮卡住的题。第三轮挑十道最不顺的，写成 60 秒逐字稿，练到不看稿也能说。

**最后一句话。** 这份目录的价值不在“列了多少”，而在每一项都能落到“我能讲清、我能写出来、我知道它在我项目里的位置”。做不到这三条，就还没学会。
